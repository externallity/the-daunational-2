ОБЩАЯ ТАБЛИЦА ИГРОКОВ

Очки игроков из комнат, сохранённых в этом браузере.

ПРАВИЛА ТУРНИРА

  • Турнир состоит из 5 сессий по 3 матча — всего 15 матчей.
  • Победа — 100 очков, поражение — 40 очков.
  • MVP матча получает дополнительно 15 очков.
  • Очки начисляются по игровому нику. Вход под другим ником означает отдельный профиль без очков прежнего ника.
  • Капитаны по очереди выбирают игроков в команды. Порядок выбора — змейкой.
  • Каждая команда выбирает по 5 уникальных героев из общего пула.
  • Организатор фиксирует результат матча.
Важно: текущая версия сохраняет данные локально в браузере. Для общей комнаты между разными устройствами требуется подключить серверную базу данных.
